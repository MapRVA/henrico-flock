# Flock ALPR locations in Herico County

GeoJSON created in R by parsing the county-provided PDF and georeferenced.

## Conflated data

This repo also contains an [Ultra](https://overpass-ultra.us) query that categorizes the data based on if it
is within 100 meters of an ALPR mapped in [OpenStreetMap](https://openstreetmap.org).
